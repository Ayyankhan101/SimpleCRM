# Product Guidelines

## Prose Style
- **Clear & Concise:** Avoid jargon where possible; explain analytical terms simply.
- **Instructive:** Use active voice for actions (e.g., "Upload your CSV" instead of "The CSV can be uploaded").
- **Professional yet Approachable:** Maintain a helpful and reliable tone.

## Branding
- **Color Palette:** A clean, data-focused palette with blues and grays, using high-contrast colors for data points in charts.
- **Typography:** Modern, sans-serif fonts (e.g., Inter, Roboto) for readability in data tables and dashboards.
- **Consistency:** Use consistent iconography for data operations (CRUD) throughout the application.

## User Experience (UX) Principles
- **Direct Manipulation:** Allow users to interact with data visualizations directly to filter or drill down.
- **Progressive Disclosure:** Show essential data first, then provide more details on demand.
- **Feedback Loops:** Provide clear loading states, success messages, and helpful error handling for data operations.
- **Aesthetic Integrity:** Ensure a visually balanced layout that prioritizes data legibility.
- **Accessibility:** Adhere to WCAG guidelines for color contrast and keyboard navigation.

## Functional Standards
- **Data Integrity:** Always validate data inputs and provide clear error feedback.
- **Performance:** Prioritize fast rendering of charts and dashboards; use lazy loading for large datasets.
- **Security:** Ensure sensitive user data is protected and authentication is always enforced.
